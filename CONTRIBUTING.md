# Contributing

- **Typo / wording / docs**: open a PR directly.
- **Behaviour change (rules, steps, output format)**: open an issue first. Every rule in `SKILL.md` is load-bearing — relaxing one usually turns the skill back into an interrogation.
- **New example**: welcome, if it shows a case the existing four do not (keep it synthetic and de-identified).
- **References**: cite the source, or say the claim is unverified. See `references/design-notes.md` for the citation discipline this project holds itself to.

Before opening a PR, load the skill once in a real session and check that it still starts with a single question.
